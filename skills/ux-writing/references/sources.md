## Conflicts resolved

- 2021 TDS rule allowed `닫기` or `다음에` for the dismiss button; the current
  guide standardizes on `닫기`. Follow the current guide.
- A 2021 push example used `종료되어요`; the current guide requires `돼요`.
  Follow the current guide.
